# 双手交互 3D 粒子系统（Particle Hands）

一个用 **Three.js + MediaPipe Hands** 实现的实时交互 3D 粒子系统：以全屏摄像头画面为背景，用双手手势控制一群粉白混合的粒子，组成文字或跳动的 3D 爱心。

> 所有依赖（Three.js、MediaPipe Hands）均通过常规 `<script>` 标签从 CDN 引入，无需打包工具，单文件 `particle_hands.html` 即可运行。

---

## 手势操作说明

| 手 | 动作 | 效果 |
| --- | --- | --- |
| **右手** | 张开手掌（≥4 指伸展） | 粒子**扩散**，并组成当前文字 |
| **右手** | 握拳（≤1 指伸展） | 粒子**收缩**汇聚成居中的 3D 爱心，按约 72 BPM（lub-dub 双跳）心跳频率跳动 |
| **右手** | 手掌旋转 | 扩散态的文字整体沿右手旋转方向做旋转轨迹运动 |
| **左手** | 伸出 **1** 根手指 | 文字切换为 **HELLO** |
| **左手** | 伸出 **2** 根手指 | 文字切换为 **好想你** |
| **左手** | 伸出 **3** 根手指 | 文字切换为 **我爱你** |

其他细节：
- **躲避左手**：任何状态下，粒子都会用排斥力避开左手手掌所在区域（左手区域留白）。
- **粉白粒子**：约 7000 个粒子在粉色与白色之间随机插值，柔和发光。
- **扩散后变化**：扩散态激活更多粒子、单个粒子更小（`uSize = 0.3`）、运动速度更慢（弹簧系数更低）。
- **爱心形态**：用隐式心形方程采样并赋 z 厚度形成 3D 体，居中于屏幕正中，下半部分左右收紧成利落尖端。

## 如何运行

摄像头采集（`getUserMedia`）要求**安全上下文**（https 或 `localhost`），因此**不能直接双击 `file://` 打开**。二选一：

### 方式一：在线运行（最简单，推荐）

本仓库已开启 GitHub Pages，直接访问：

```
https://mbf888.github.io/heart/particle_hands.html
```

这是 https 地址，浏览器会正常弹出摄像头授权，允许即可体验。

> 若打不开，确认仓库 Settings → Pages 已选 `main` 分支、`/(root)` 目录并保存（首次开启约 1 分钟生效）。

### 方式二：本地运行

在本仓库目录下起一个本地静态服务器（localhost 属安全上下文）：

```bash
# 进入仓库目录后
python -m http.server 8000
```

然后浏览器打开 `http://localhost:8000/particle_hands.html`，允许摄像头权限。

也可以使用任意静态服务器（如 `npx serve`、VS Code Live Server 等），只要地址是 `http://localhost:...` 或 `https://...` 即可。

## 浏览器 / 权限提示

- 首次打开会请求**摄像头权限**，请点击"允许"。
- 建议使用 **Chrome / Edge / Firefox** 最新版；若摄像头灯不亮，检查浏览器地址栏的权限图标是否被拦截。
- 需要联网（CDN 加载 Three.js 与 MediaPipe 模型）。
- 页面左下角有实时 HUD，显示当前文字模式、右手状态与左手手指数，方便调试。

## 自定义参数（进阶）

打开 `particle_hands.html` 可调整：
- `WORDS`：左手 1/2/3 对应的文字。
- `uSize`：粒子大小（当前 0.3）。
- 爱心收紧系数（约 `0.45`）：调整爱心下半左右收紧程度。
- 心跳 BPM、扩散/收缩弹簧系数、粒子数量等。
